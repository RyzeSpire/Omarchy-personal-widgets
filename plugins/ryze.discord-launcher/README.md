# Discord desktop launcher

The streamlined Discord glyph is gray when Discord is closed and blue while a native Discord process is running, including tray, Electron helper and updater processes. An existing Discord web-app window also counts as Discord running. Status refreshes every two seconds; it does not start Discord.

Click to open or focus the native desktop client on workspace 8. This uses the installed discord launcher and preserves the existing HDMI-A-1 preference. A tray instance is restored through the same launcher. Web-app windows are never reused by the desktop launch action.
